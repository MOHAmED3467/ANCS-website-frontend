# ANCS Website Frontend

ANCS is an AI-powered network automation platform built as a graduation project. The frontend is a Vue 3 / Vite single-page application for presenting the product, managing downloads, and providing access to the ANCS documentation.

## What is ANCS?

ANCS stands for Autonomous Network Configuration & Orchestration System. It helps networking students and engineers:

- Generate network device configurations automatically
- Manage multi-vendor devices and lab topologies
- Integrate with GNS3 for live discovery and sync
- Use an AI Copilot assistant for network troubleshooting and deployment
- Securely deploy SSH/Telnet configurations and track changes

## Key Pages

- `Home` — product overview, tech stack, and feature summary
- `About` — project vision, workflow, and technology highlights
- `Features` — detailed capabilities and automation benefits
- `Download` — latest ANCS executable distribution link
- `Team` — project team section
- `Contact` — contact information and links
- `Book` — graduation book access via Google Drive and local download

## Technology Stack

- Vue 3
- Vite
- Pinia
- Vue Router
- Vuetify
- Axios
- Font icons via Font Awesome

## Project Setup

Install dependencies:

```sh
npm install
```

Run development server:

```sh
npm run dev
```

Build production bundle:

```sh
npm run build
```

Preview production build:

```sh
npm run preview
```

Format source files:

```sh
npm run format
```

Lint project files:

```sh
npm run lint
```

## Notes

- The frontend uses a remote backend for authentication and Google login integration.
- The `public/` folder contains static assets such as the graduation book PDF and logo.
- Unused starter components were removed to keep the codebase clean.
